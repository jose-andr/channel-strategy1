## Purpose

This decision log records key decisions made during Channel Strategy Y2.

It helps the project team, sponsors and stakeholders understand:

| This log helps us track | Why it matters |
| --- | --- |
| What decision was made | Avoids revisiting the same issue repeatedly |
| Who made the decision | Makes accountability clear |
| Why the decision was made | Preserves context and rationale |
| What options were considered | Shows trade-offs and supports transparency |
| What the decision affects | Helps manage scope, risks and dependencies |
| Whether follow-up is needed | Keeps actions visible |

Channel Strategy Y2 involves connected work across CX, Digital, Salesforce / CRM, Knowledge, Data, Privacy, Records, Information Security, Communications, Contact Centre and selected service owners. Decisions need to be visible so related workstreams stay aligned.

## Decision principles

Use these principles when making and recording decisions.

| Principle | Meaning |
| --- | --- |
| Customer value first | Decisions should improve customer clarity, effort, continuity or confidence |
| Connected interactions over channel optimisation | Avoid improving one channel in a way that worsens the end-to-end journey |
| Minimum viable before enterprise-wide | Prefer testable patterns that can be validated through selected journeys |
| Reuse before reinvention | Create patterns, standards and tools that can be applied across services |
| Evidence before preference | Use demand, customer effort, repeat contact, staff pain points and feasibility evidence |
| Equity and accessibility by design | Maintain assisted access, language options and WCAG-aligned digital pathways |
| Compliance built in early | Consider privacy, records, information security and data governance before testing |
| Clear ownership | Every decision should have an accountable owner and next step |

## Escalation guidance

Escalate a decision when one or more of the following applies:

| Escalation trigger | Escalate to |
| --- | --- |
| Decision changes agreed scope, timeline or value drops | Sponsor / CX leadership |
| Decision affects multiple teams or creates unresolved conflict | Sponsor / working group |
| Decision has privacy, records, security or data governance implications | Relevant governance forum |
| Decision requires platform change, integration or technical investment | Technology / Digital governance |
| Decision affects public-facing commitments or customer expectations | Sponsor and Communications |
| Decision affects accessibility, language access or equity of access | CX leadership and relevant advisory input |
| Decision requires funding or FY26/27 planning commitment | ELT / senior leadership |
